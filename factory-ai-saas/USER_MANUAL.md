## 1. 系统概述

### 1.1 产品定位

工厂AI SaaS是面向中小制造企业的智能化管理平台，核心解决三大痛点：

- **报价慢**：传统人工核价需要数小时，AI核价10秒出结果
- **跟单乱**：订单进度不透明，交付延期频发
- **算账难**：成本利润算不清，年底不知道赚了多少

### 1.2 核心功能

| 模块 | 功能 | 核心价值 |
|------|------|----------|
| AI智能报价 | BOM管理、AI核价、审核流程、一键转订单 | 报价效率提升10倍 |
| 订单跟踪 | 生产进度、发货管理、完成确认 | 订单进度实时掌握 |
| 成本核算 | 成本记录、收款登记、利润分析 | 每单利润一目了然 |
| 算力充值 | 套餐购买、支付管理、消费记录 | AI服务按需付费 |
| ERP同步 | 钉钉/用友/金蝶对接、数据双向同步 | 避免重复录入 |

### 1.3 技术架构

- 前端：React + Ant Design 响应式管理后台
- 后端：NestJS 模块化单体架构（可演进为微服务）
- 数据库：支持 MySQL / SQLite
- 多租户：共享数据库 + tenant_id 隔离模式

## 5. AI智能报价

AI报价是系统的核心功能模块，支持从报价创建到AI核价、审核、转订单的完整流程。

### 5.1 报价单状态流转

```
草稿(draft) → 待审核(pending) → 审核中/已审核(reviewing) → 已确认(confirmed)
                                          ↓
                                      已驳回(rejected) → 可重新编辑
```

| 状态 | 说明 | 可执行操作 |
|------|------|-----------|
| 草稿 | 刚创建，可编辑 | AI核价、提交审核、删除 |
| 待审核 | 已提交等待老板审核 | 查看（等待审核） |
| 已确认 | 老板审核通过 | 转为订单 |
| 已驳回 | 审核不通过 | 重新编辑后再次提交 |

### 5.2 新建报价单（业务员操作）

**操作步骤：**

1. 进入左侧菜单【AI报价】
2. 点击右上角【新建报价】按钮
3. 填写报价信息：
   - **产品名称**（必填）：例如"不锈钢外壳"
   - **客户**（必填）：从下拉列表选择，或点击下拉框底部【新建客户】快速添加
   - **数量**（必填）：订单数量
   - **毛利率**（%）：期望利润率，默认20%
   - **备注**：产品规格、技术要求等补充说明
4. 点击【创建】，系统自动生成报价单并进入详情页
5. 在报价详情页补充BOM物料清单和工序信息

### 5.3 维护BOM物料清单

在报价详情页，可添加物料明细：
- 物料名称、材质/规格、数量、单位
- 单价和小计金额（可手动填写或由系统自动计算）

### 5.4 AI智能核价（核心功能）

**前提条件：**
- 账户有足够的AI算力余额（每次核价消耗 ¥1 + 1次次数）
- 新用户赠送 ¥100 + 50次，足够体验50次核价

**操作步骤：**

1. 在报价列表或详情页，点击【🤖 AI智能核价】按钮
2. 系统会：
   - 自动检查算力余额
   - 调用AI核价引擎分析BOM和工序
   - 2-3秒后返回AI建议报价
3. 核价成功后，报价单会显示：
   - 预估成本（基于物料+人工+费用）
   - AI建议价格
4. 核价完成后点击【提交】，报价单进入【待审核】状态

> 💡 **注意**：AI核价结果仅供参考，老板可在审核环节调整最终价格。

### 5.5 审核报价（老板操作）

1. 进入报价详情页（待审核状态）
2. 查看AI建议价格和预估成本
3. 点击【审核报价】按钮：
   - 可调整最终报价金额
   - 填写审核意见（可选）
4. 点击【通过】完成审核，报价状态变为【已确认】
5. 若价格有问题可点击【驳回】，让业务员修改后重新提交

### 5.6 报价转订单

审核通过后（状态为已确认）：
1. 在报价详情页点击【转为订单】
2. 系统自动创建对应订单，携带报价单上的产品、客户、数量、金额信息
3. 自动跳转到新创建的订单详情页

### 5.7 主数据管理

点击AI报价页面的【主数据】按钮打开抽屉，可管理三类基础数据：

#### 5.7.1 客户管理
- **新增客户**：填写客户名称、联系人、电话
- 客户信息在新建报价时可直接选择
- ERP同步可批量导入客户（见第9章）

#### 5.7.2 物料管理
- 维护常用物料：名称、编码、规格、单位、单价、分类、供应商
- 物料用于BOM清单快速选取

#### 5.7.3 工序管理
- 维护生产工序：名称、编码、每小时人工费、所属车间
- 工序用于成本核算中的人工成本计算

## 6. 订单跟踪

订单模块管理从报价转单到交付完成的全流程。

### 6.1 订单状态流转

```
待排产(pending) → 生产中(production) → 已发货(shipped) → 已送达(delivered) → 已完成(completed)
                                                                      ↓
                                                              已取消(cancelled)
```

| 状态 | 进度 | 说明 |
|------|:----:|------|
| 待排产 | 10% | 刚从报价单生成，等待安排生产 |
| 生产中 | 40% | 车间正在生产，可更新进度节点 |
| 已发货 | 70% | 货物已发出，等待客户签收 |
| 已送达 | 85% | 客户已收到货 |
| 已完成 | 100% | 交易完成，可进行成本核算 |

### 6.2 订单列表

- 默认显示所有订单，支持按订单号、产品名称、客户名称搜索
- 每条订单显示：订单号、产品、客户、数量、金额、状态进度条、交货期
- 进度条直观展示当前生产完成百分比

### 6.3 更新生产进度（跟单员操作）

生产中状态的订单可更新进度：

1. 在订单列表点击【更新进度】按钮
2. 填写进度信息：
   - **当前阶段**：备料/生产中/质检/包装/待发货
   - **进度(%)**：0-100的数字
   - **预计完成日期**：选择日期
   - **备注**：异常情况说明
3. 提交后，进度记录会追加到订单详情的生产时间线中

### 6.4 发货操作

生产完成后：
1. 点击【发货】按钮
2. 确认发货信息后提交
3. 订单状态变为【已发货】，进度70%

### 6.5 完成订单

客户确认收货且款项结清后：
1. 点击【完成】按钮
2. 订单状态变为【已完成】，进度100%
3. 建议同步在【成本核算】模块记录该订单的成本和收款

### 6.6 订单详情

点击订单号进入详情页，可查看：
- **核心指标卡**：订单金额、已收款、成本、利润
- **订单信息**：产品、客户、数量、交货期、备注
- **生产进度追踪时间线**：按时间顺序展示所有进度更新记录

## 7. 成本核算

成本模块帮助工厂记录每笔支出和收入，自动计算利润。

### 7.1 核心指标

成本页面顶部展示4个关键财务指标：
- **本月收款**：本月所有收款记录总和
- **本月成本**：本月所有成本记录总和
- **本月利润**：收款 - 成本
- **利润率**：利润 / 收款 × 100%

### 7.2 利润趋势图

柱状图展示近6个月的：
- 绿色柱：收入
- 红色柱：成本
- 蓝色柱：利润

直观展示月度经营状况。

### 7.3 记录成本

**操作步骤：**

1. 切换到【成本记录】标签页
2. 点击【记一笔成本】
3. 填写信息：
   - **日期**：成本发生日期
   - **类型**：原料/人工/设备/运费/其他
   - **金额**：支出金额
   - **描述**：说明成本用途（可关联订单号）
4. 提交保存

> 💡 **建议**：成本记录关联订单号，后续可按订单维度统计利润。

### 7.4 记录收款

**操作步骤：**

1. 切换到【收款记录】标签页
2. 点击【记一笔收款】
3. 填写信息：
   - **收款日期**
   - **金额**
   - **收款方式**：银行转账/微信/支付宝/现金
   - **备注**：可注明对应订单和客户
4. 提交保存

### 7.5 订单级成本分析

在订单详情页可查看该订单的：
- 订单金额
- 已收款项
- 累计成本
- 订单利润（订单金额 - 成本）

## 9. ERP数据同步

ERP同步模块支持与主流ERP系统对接，实现客户、物料、工序、订单数据的双向同步，避免重复录入。

### 9.1 支持的ERP系统

| ERP类型 | 说明 | 适用产品 |
|---------|------|---------|
| 钉钉 | 钉钉宜搭 / 钉钉ERP连接器 | 使用钉钉办公的工厂 |
| 用友 | 用友U8 / U9 / NC系列 | 国内主流ERP |
| 金蝶 | 金蝶K3 / 金蝶Cloud | 华南地区常用ERP |
| 自定义API | 通过标准REST API对接 | 自研系统或小众ERP |

### 9.2 ERP配置（老板/跟单员操作）

**操作步骤：**

1. 进入左侧菜单【ERP同步】
2. 查看当前连接状态
3. 填写连接配置：
   - **ERP类型**：选择对应的系统
   - **名称**：自定义名称，如"公司用友U8"
   - **启用状态**：开启/关闭
   - **API地址**：ERP接口地址（钉钉/用友/金蝶有默认地址）
   - **AppKey / AppSecret**：在ERP开放平台申请的应用凭证
4. 配置同步选项：
   - 勾选需要同步的数据类型：客户/物料/工序/订单
   - 是否自动推送报价单到ERP
   - 同步间隔（分钟）：最低5分钟
5. 点击【保存配置】

### 9.3 测试连接

配置完成后，点击【测试连接】按钮验证配置是否正确。
- 连接成功：显示绿色提示和响应时间
- 连接失败：显示红色错误提示，请检查API地址和密钥

### 9.4 手动同步

有两种方式触发同步：

1. **立即同步全部**：点击红色【立即同步全部】按钮，一次性同步客户+物料+工序
2. **单个类型同步**：在"快捷同步"区域点击对应按钮：
   - 🔄 同步客户
   - 🔄 同步物料
   - 🔄 同步工序
   - 🔄 同步订单

> ⏱️ 同步过程通常需要数秒到1分钟，同步完成后会自动刷新。

### 9.5 同步日志

页面底部表格展示所有同步历史记录：
- **时间**：同步执行时间
- **数据类型**：客户/物料/工序/订单
- **方向**：拉取（从ERP到本系统）/ 推送（从本系统到ERP）
- **状态**：等待/同步中/成功/失败
- **结果统计**：总计多少条/成功多少/失败多少
- **耗时**：同步持续时间
- **错误信息**：失败时显示原因

> 💡 同步执行后会自动创建演示数据（如ERP-华为科技、ERP-冷轧钢板等）用于测试体验。

### 9.6 自动同步

配置启用后，系统会按照设定的同步间隔自动执行后台同步，无需手动操作。同步结果可在同步日志中查看。

## 11. 常见问题 FAQ

### Q1：AI核价一次扣多少钱？

每次AI核价统一扣费：**¥1元 + 1次核价次数**，优先使用次数，次数用完后从余额扣费。新用户赠送¥100+50次，可免费体验约50次核价。

### Q2：算力用完了怎么办？

进入【算力充值】页面购买套餐，支持支付宝/微信支付（演示环境为模拟支付）。充值后算力实时到账。

### Q3：不同角色登录看到的菜单不一样？

是的，系统根据用户角色自动过滤菜单和操作权限。例如业务员看不到成本和ERP菜单，财务看不到报价创建按钮。具体权限参见第3章权限矩阵。

### Q4：如何添加新员工账号？

使用老板账号登录，进入【系统设置】→【用户管理】→【新增用户】，填写信息并分配角色即可。初始密码默认为123456，员工登录后可自行修改（后续版本开放）。

### Q5：AI核价结果准确吗？

AI核价基于BOM物料清单、工序工时、历史数据综合计算，准确率可达90%以上。但建议老板审核时根据实际情况微调最终价格，AI结果作为参考基准。随着使用数据积累，核价会越来越精准。

### Q6：可以接入我们自己在用的ERP吗？

支持。进入【ERP同步】选择"自定义API"类型，按照API文档配置对接地址和密钥即可。标准钉钉/用友/金蝶有预置连接器，配置更简单。

### Q7：数据安全吗？会不会泄露？

- 多租户架构通过 `tenant_id` 严格隔离数据，A租户看不到B租户的任何数据
- 密码采用bcrypt加密存储，即使数据库泄露也无法还原明文密码
- JWT Token有过期时间，建议生产环境配置HTTPS
- 支持私有化部署（需购买企业版license）

### Q8：忘记密码怎么办？

请联系企业管理员（老板账号），在用户管理中对该用户执行【重置密码】，重置后密码为 `123456`。

### Q9：可以导出报价单或订单吗？

当前版本支持页面查看，后续版本将提供PDF导出和Excel导出功能。

### Q10：系统支持多少用户同时使用？

SaaS版本无硬性用户数限制，建议单租户不超过100用户。私有化部署可根据服务器配置扩展。
